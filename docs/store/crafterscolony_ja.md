# Block Video Player — 自分の動画をマイクラのブロックで再生

**好きな動画を、本物のブロックで、音つきで再生できる統合版のアドオンです。** 平面のスクリーンだけでなく、まわりを歩ける 3D ホログラムや、見ている人の目の位置に合わせて描き直す「だまし絵」の踊る人物も作れます。**チートも「試験的な機能」もいりません。** 自分の動画の変換は無料で、ブラウザだけでできます。

このファイルは **ショーケース版** です。オリジナルのアニメ、3D ホログラム 3 本、だまし絵で踊る女の子が入っています。

（画像: gif_cat_ja.gif）

## ▶ ショーケースを試す (約 3 分)

1. `.mcaddon` をダブルクリックして Minecraft に読み込みます。
2. ワールドを作り、**ビヘイビアーパックとリソースパックの両方** を有効にします (名前は同じです)。スーパーフラットがおすすめです。**チートはオフのままで大丈夫です。**
3. 平らで開けた場所に立ち、チャットで **`/badapple:setup`** → **`/badapple:start`**。
4. **コンパスを使う** とリモコンが開きます (再生・一時停止・シーク・音量・動画の切り替え)。

**Minecraft 統合版 1.26.10 以降が必要です。** それより古い Minecraft では、GitHub の [v6.31.0](https://github.com/ntk758/MinecraftAddon_Bedrock_Video-Player/releases/tag/v6.31.0) を使ってください (こちらはチートが必要です)。

**入っている動画** (`/badapple:play <動画ID>` か、リモコンの「動画リストから選択」で切り替え。`/badapple:list` で ID を確認できます):

| 動画 ID | 内容 |
|---|---|
| `screen` | オリジナルの 15 秒のアニメ (音楽つき、128×72 の平面)。夕焼け・花火・虹・オレンジの猫 |
| `walk` | 歩く人影を丸くふくらませた 3D の人形 |
| `waves` | カラフルな波の風景を、明るさを奥行きにした 3D のレリーフに |
| `bounce` | しま模様のボールが床で跳ねる MagicaVoxel の立体アニメ |
| `dancer` | 床と後ろの壁に描く、だまし絵で踊る女の子 (壁ではアニメを再生)。歩いても飛んでも、こちらから見て立って踊り続けます |

置かれる場所: 平面は足元から東と北へ広がります。3D は 2 ブロック北に立ちます。`dancer` の舞台は約 118 × 51 ブロック、壁の高さ 84 ブロックで、北側にできます (舞台の前か、床の上から見てください)。スクリーンは邪魔なブロックを置き替えるので、何も無い場所で使ってください。

## 🎞 自分の動画をマイクラに

1. 無料の **[ブラウザ版の変換ツール](https://ntk758.github.io/MinecraftAddon_Bedrock_Video-Player/)** を開きます。Windows・Mac・Linux・Chromebook で使え、インストールは不要。**動画はどこにも送信されません** (パソコンの中で変換します)。
2. 動画 (MP4 など)・画像・カメラで撮った動画・MagicaVoxel の `.vox`・MMD のモデルと踊りを選び、**「.mcaddon を作る」** を押します。
3. ページの上で、**ゲームの中での見え方をプレビュー** できます (元の動画と並べて、全部のコマを音つきで)。できた `.mcaddon` はショーケースと同じように使えます。

大きな画面・速い変換・AI での人物の切り抜きは、無料の **Windows 版** (下) でできます。

（画像: gif_moon_ja.gif）

## ✨ 特徴

- **本物のブロック・実測の色**: コンクリート・テラコッタ・羊毛・木材・石・鉱石など最大 221 色。色はゲームのテクスチャから実測し、シーンごとに合う 24〜127 色を選びます。
- **歩いて見られる 3D ホログラム**: 明るさを奥行きにした **レリーフ**・明るい部分の **押し出し**・丸く **ふくらませた** 立体、MagicaVoxel の立体アニメ。
- **だまし絵**: 人物を、見ている人の目の位置から見たとおりに床と壁へ描き、動くと描き直します。正面・上・横のどこから見ても立って見えます。後ろの壁で動画も流せます (正しく見えるのは 1 人)。
- **3D 版と平面版をセットで**: チェックを 1 つ入れると、同じ動画の普通の平面版 (`<動画ID>_flat`) も一緒に入れられます。音声は 1 回分だけなので、アドオンはほとんど大きくなりません。
- **音もぴったり**: 一時停止やシークにも合わせて鳴ります。
- **チート・試験的な機能が不要**: コマンドは普通のワールドで使えます (オペレーターが使えます)。安定版の Script API だけを使っています。
- **ワールドの邪魔をしない**: スクリーンを読み込んだままにする区画はこのアドオン専用の枠で登録するので、ワールドの常時読み込みの上限 (10 個) を使いません。
- **ファイルが小さい**: 変わったブロックだけを送り、8×8 の範囲ごとに一番小さい描き方を選んで圧縮します。
- **10 言語対応**: 日本語・English・简体中文・繁體中文・한국어・Español・Português・Français・Deutsch・Русский。ゲーム内のメッセージとリモコンは、各プレイヤーのゲームの言語で表示します。

## ⌨ コマンド

| コマンド | すること |
|---|---|
| `/badapple:setup` | 立っている場所にスクリーンを置く。後ろに `wall` でテレビのように立ててこちらに向ける、`face` で見ている方向に向ける、`align` でまたぐチャンクが少なくなるよう最大 15 ブロックずらす |
| `/badapple:start` | 選んでいる動画を再生 (続きから再生) |
| `/badapple:play <動画ID>` | 動画を選んで再生 |
| `/badapple:stop` | 止めてスクリーンを消す |
| `/badapple:list` | 動画の一覧と動画 ID |
| `/badapple:remote` | リモコンを開く (コンパスと同じ) |
| `/badapple:render auto\|rect\|list\|block` | ブロックの置き方 (`auto` がおすすめ) |
| `/badapple:bench` | その端末でブロックを置く速さを計る (`auto` が使います) |
| `/badapple:stats` | 前回の再生の実際の fps・サーバーの TPS・遅れたフレーム |

これまでの `/scriptevent badapple:...` も使えます (こちらはチートが必要)。`badapple` はショーケースの接頭辞で、自分で作るアドオンでは作るときに決めた接頭辞になります。

## 🖥 Windows 版 (速い・大きい・小さいアドオン)

- [GitHub のリリース](https://github.com/ntk758/MinecraftAddon_Bedrock_Video-Player/releases/latest) から `BlockVideoPlayer-…-windows-x64.zip` をダウンロードして解凍し、`BlockVideoPlayer.exe` を起動 (Python は不要)。
- FFmpeg を `winget install Gyan.FFmpeg` で入れるか、`ffmpeg.exe` を EXE と同じフォルダに置きます。
- 初めて起動すると「はじめてガイド」が、パソコンの環境を調べ、動画に合う設定と、できた後の再生のしかたを案内します。
- NVIDIA・AMD・Intel の GPU があれば使い、無ければ CPU で変換します。
- **AI で人物を切り抜き**: ダンス動画の人物を丸い 3D の人形に (だまし絵なら、人物を抜いた動画を後ろの壁に)。アニメ・イラストの人物用の AI もあります。

## 🧊 3D のモード

| モード | 向いているもの |
|---|---|
| レリーフ (明るさ = 奥行き) | 風景・CG・グラデーション |
| 押し出し (シルエット) | 白黒の動画・影絵の MV |
| ふくらみ (丸く) | シルエット・ロゴ |
| 人物の切り抜き (AI・Windows 版) | ダンス動画 |
| MagicaVoxel (`.vox`) | ボクセルアート・立体アニメ (シーングラフ・キーフレーム対応) |
| MMD (`.pmx` + `.vmd`) | 踊る 3D モデル |
| ＋ だまし絵 (オプション) | 上のどれでも (人物の高さは約 64 ブロックまでがおすすめ) |
| ステンドグラスのパレット | 透ける 3D (16 色) |

## 💡 コツ

- 画面が大きいほどきれいですが、重くなります。256×256 以上はパソコンがおすすめです。
- 一度 `/badapple:bench` を実行すると、その端末の速さに合わせて置き方を選びます。再生の後に `/badapple:stats` で実際の fps が分かります。目標よりずっと低ければ、画面を小さくするか fps を下げてください。
- ゲームがブロックを置けなかったときは、理由をチャットに 1 回だけ表示します。コメントで教えてもらえると助かります。

## ❓ よくある質問

- **Java 版で使えますか?** 使えません。統合版だけです。
- **スマホやゲーム機では?** 安定版の Script API だけなので、統合版ならどの機種でも動くはずですが、まだパソコンでしか確かめていません。小さい画面から試して、動き具合をコメントで教えてください。
- **`/badapple:play` の後ろで動画 ID が候補に出ません。** Minecraft 側の制限とみられます。`/badapple:list` で ID を確かめてから入力してください。
- **自分のものではない動画を変換してもいいですか?** 使う権利のある動画だけを変換してください。ショーケースの絵と音楽はすべて一から作ったものです。
