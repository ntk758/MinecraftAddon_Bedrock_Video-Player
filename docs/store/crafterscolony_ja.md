概要

本物のブロックで動画を再生できるアドオンです。音声付きで、3D ホログラムにもできます。チートをオンにしなくても遊べます。

動画 (MP4 など) をブロックに変換し、ワールドの中に大きなスクリーンを作って音声と一緒に再生します。明るさを奥行きにした立体や、人影をふくらませた立体にして「動く 3D 像」として再生したり、MagicaVoxel で作った立体アニメ (.vox) を動かしたりもできます。

自分の動画を 3 ステップで
無料の ブラウザ版の変換ツール

https://ntk758.github.io/MinecraftAddon_Bedrock_Video-Player/

を開きます。Windows・Mac・Chromebook のほか、スマホのブラウザでも動き (iPhone で確認)、インストールは不要です。動画はパソコンの中で変換され、どこにも送信されません。

動画 (MP4 など。画像・カメラで撮った動画・MagicaVoxel の .vox・MMD のモデルと踊りも可) を選んで「.mcaddon を作る」を押します。作り終えると、ゲームの中での見え方をページの上でプレビューできます (元の動画と並べて、全部のコマを音つきで)。
できた .mcaddon を Minecraft で開き、見たい方向を向いて /badapple:setup wall (テレビのように立てる) か /badapple:setup (床置き) をして、コンパスで再生します。

もっと大きな画面・小さなファイルにしたいときは、Windows 版の変換ツール (下の「自分の動画でアドオンを作る」) を使ってください。

このページのファイルは、すぐに遊べる映像が 5 本入ったお試し用アドオン です。曲付きの自作の短いアニメと、3D ホログラムが 3 本、見ている人の目に合わせて描く「だまし絵」の踊る人物が入っています。絵も音もすべて作者が一から作ったものです。

主な特徴
チートのオンは不要: /badapple:setup などの短いコマンドは、チートをオフのままのワールドで使えます (v6.32.0 から)
最大 221 種類の本物のブロックで映像を描く: コンクリート・テラコッタ・羊毛・木材・原木・石・鉱石など。色はゲームのテクスチャから測っています (1 シーン最大 127 色)。ぴったりのブロックが無い色は、近い 2 つのブロックを混ぜて表します
音声付き: 一時停止・シーク (早送り・巻き戻し) にも音声がついてきます
好きな向きに置ける: setup wall でテレビのように立てたり、setup face で見ている方向に向けたりできます
3D ホログラム: 明るさを奥行きにした「レリーフ」、明るい部分を押し出した「シルエット」、丸くふくらませた「ふくらみ」、MagicaVoxel (.vox) の立体アニメ。立体はブロックの側面の色で選ぶので、原木は樹皮の色で使われます
3D 版と平面版をセットで: 変換ツールでチェックを 1 つ入れると、同じ動画の普通の平面版も一緒に入れられます。音声は 1 回分だけなので、アドオンはほとんど大きくなりません (v6.31.0 から)
ステンドグラスのホログラム: 向こうが透けて見える 16 色
コンパスでリモコン操作: 再生・一時停止・停止・シーク・音量・前後の動画・動画の一覧。選んだ動画にすぐ切り替わります
1 つのアドオンに複数の動画 を入れられます
なめらかな再生: 変わったブロックだけを置き、置き方もフレームごとに一番速い方法を選びます
ワールドの邪魔をしない: スクリーンを読み込んだままにする区画はこのアドオン専用の枠で登録するので、ワールドの常時読み込みの上限 (10 個) を使いません (v6.32.0 から)
小さなアドオン: 動画のデータを強く圧縮しています (v6.14 より約 3 割小さく)
10 言語対応: メッセージとリモコンは各プレイヤーのゲームの言語 (日本語・英語など) で表示されます
実験的機能のオンは不要: 安定版の Script API だけを使っています

導入方法と遊び方
ダウンロードした .mcaddon を開いて Minecraft に読み込みます (ダブルクリック、またはスマホでは Minecraft で開く)。
ワールドの設定で、ビヘイビアーパックとリソースパックの両方 を有効にします (同じ名前のパックです)。チートはオフのままで大丈夫です。
広くて平らな場所に行きます (スクリーンはその場所にあるブロックを置き換えます。大事な建物の近くでは使わないでください)。
スクリーンを置きたい場所でチャット欄に /badapple:setup と入力します。スクリーンは足元から北東へ、映像の面が上を向いた床置きで作られます。テレビのように立てたいときは、見たい方向を向いて /badapple:setup wall と入力します。
コンパス を使う (右クリック / 長押し) とリモコンが開くので、「再生 / 再開」を押します。/badapple:start でも再生できます。

入っている 5 本の映像は、リモコンの「動画リストから選択」か、/badapple:play <ID> で切り替えられます。ID は /badapple:list で確かめられます (/badapple:play の後ろで ID が入力の候補に出ないため。下の「注意事項」)。

ID	内容
screen	128×72 ブロックの平面スクリーンで見る、曲付きの自作アニメ (15 秒): 夕焼け、夜の花火、虹と、オレンジ色の猫
walk	歩く人影を丸くふくらませた 3D の人型
waves	カラフルな波の模様を、明るさを奥行きにした 3D レリーフ
bounce	MagicaVoxel の立体アニメ: しま模様のボールが床で跳ねる
dancer	だまし絵: 踊る女の子 (自作) を、見ている人の目に合わせて床と後ろの壁に描きます。後ろの壁には見本アニメが流れます。前を歩いたり飛んだりしても、立って見えます

平面スクリーンは足もとから東と北へ広がります。3D ホログラムは自分の 2 ブロック北に、自分を中心にして立ちます (高さの上限を超えるときは自動で下にずらします)。dancer の舞台は北側に約 118 × 51 ブロック、後ろの壁の高さ 84 ブロックで作られます。

コマンド一覧
コマンド	内容
/badapple:setup	今いる場所にスクリーンを置く
/badapple:setup wall	見ている方向の 3 ブロック先に、スクリーンをテレビのように立てて置く
/badapple:setup face	床置きのまま、見ている方向へ広がるように置く (3D もこちらを向く)
/badapple:setup align	またがるチャンクが少なくなるよう、最大 15 ブロックずらして置く
/badapple:start	選んでいる動画を最初から再生
/badapple:play <ID>	指定した動画を再生
/badapple:list	入っている動画の一覧
/badapple:remote	リモコンを開く (コンパスと同じ)
/badapple:stop	再生を止めてスクリーンを消す
/badapple:render auto	ブロックの置き方を選ぶ (auto がおすすめ。ほかに rect / list / block)
/badapple:bench	この端末のブロックを置く速さを測る (auto が使います)
/badapple:stats	直前の再生の実際のフレームレート・TPS・遅れたフレーム数を表示

これまでの /scriptevent badapple:setup などのコマンドも、そのまま使えます (こちらはチートをオンにする必要があります)。サーバーでは、オペレーターの権限が必要です。
自分の動画でアドオンを作る

変換ツールは無料で、どれも作者が公開しているものです。作ったアドオンのコマンドは、/badapple: の部分が変換ツールで決めた名前 (接頭辞) になります。

ブラウザ版 (インストール不要、ベータ版):

https://ntk758.github.io/MinecraftAddon_Bedrock_Video-Player/

Windows・Mac・Chromebook・スマホなどのブラウザで、動画を選んで「.mcaddon を作る」を押すだけです。画像 (止まったブロックアートになります)・カメラで撮った動画・MagicaVoxel の .vox・MMD のモデルと踊り (.pmx + .vmd) も変換できます。動画はブラウザの中で変換され、どこにも送信されません。作り終えると、ゲームの中での見え方を元の動画と並べてプレビューできます。

Windows 版 (速く、アドオンも小さい):

https://github.com/ntk758/MinecraftAddon_Bedrock_Video-Player/releases/latest

BlockVideoPlayer-…-windows-x64.zip を解凍して BlockVideoPlayer.exe を起動します (Python は不要。FFmpeg は別に必要です。入れ方はリンク先に書いてあります)。GPU で速く変換できます。ダンス動画の人物を AI で切り抜いて 3D やだまし絵にすることもできます。

画面の「再生負荷の目安」が「重い」と出たら、幅・高さ・FPS を下げると、ゲームの中でなめらかに再生できます。

注意事項
Minecraft 1.26.10 以降 が必要です。それより古い Minecraft では、GitHub の v6.31.0 (1.21.80 以降・チートが必要) を使ってください。
https://github.com/ntk758/MinecraftAddon_Bedrock_Video-Player/releases/tag/v6.31.0
前の版から更新したときは、アドオンを上書きで読み込んだ後、ワールドで一度 /badapple:setup をし直してください (前の版が作った常時読み込みの区画を外します)。
/badapple:play の後ろで、動画の ID が入力の候補に出ません (Minecraft 側の制限とみられます)。/badapple:list で ID を確かめてから入力してください。
スクリーンや立体は、その場所にあるブロックを置き換えます。建物の近くや大事なワールドでは使わず、テスト用のワールドで試してください。
大きな画面・高い FPS の動画は、端末によってはカクつきます。/badapple:stats で実際の速さを確かめられます。
自分で変換した動画の扱いに注意してください: 他人が作った動画 (アニメ・MV・配信の切り抜きなど) を変換したアドオンを配布すると、著作権の侵害になることがあります。配布するのは、自分で作った動画や、配布が許可されている動画だけにしてください。

音が出ないとき
ワールドの設定で、ビヘイビアーパックと リソースパック の両方が有効か確かめてください (音声はリソースパックに入っています)。

アドオンを読み込んだ後、Minecraft を一度終了して起動し直してください。
動画に音声が入っていないときは、再生を始めたときにチャットでお知らせします。iPhone のブラウザ版で作ったアドオンに音声が入らない問題は v6.29.1 で直しました。古い版で作った場合は作り直してください。
