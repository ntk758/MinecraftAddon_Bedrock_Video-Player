# 既知の問題と回避策 / Known issues and workarounds

## 再生 (Minecraft)

| 問題 | 原因 | 回避策 |
|---|---|---|
| 再生が重い・カクつく・映像が音声より遅れる | 1 tick (50 ms) に置けるブロックには限りがあり、画面の大部分が変わる場面では次のフレームに間に合わない。映像が遅れても音声は実時間で進むので、次の 10 秒の区切りで音声を映像の位置から鳴らし直すまでずれが残る | 幅・高さ・fps を下げる (GUI の「再生負荷の目安」が「重い」なら下げる)。`/scriptevent <接頭辞>:stats` で遅れたフレーム数と映像の遅れを確かめられる ([PERFORMANCE.md](PERFORMANCE.md)) |
| 立体が描画の途中で一瞬欠けて見える (v6.5.0 以前) | 1 フレームで変わるブロックが多いと描画が何 tick にもまたがり、古い面を空気にしてから新しい面を置いていた | v6.5.1 で、新しいブロックを先に置いて空気にするのを最後にした (途中は一瞬厚く見える) |
| スクリーンの範囲のブロックが消える | スクリーン (立体) の範囲は上書きされる。元に戻す機能は無い | 平らで何もない場所 (スーパーフラットなど) で `setup` する |
| 遠くに行くと再生が止まる・画面が欠ける | 読み込まれていないチャンクにはブロックを置けない。アドオンは常時読み込み (tickingarea) を登録するが、Minecraft の上限 (ワールド全体で 10 個) と、このアドオンの上限 (8 個) がある | スクリーンの近くで見る。ほかのアドオンや `/tickingarea` で上限を使い切っていないか `/tickingarea list` で確かめる |
| 立体が下にずれて置かれる | 建築できる高さ (オーバーワールドは Y=-64〜319) からはみ出すため、自動で下げている (チャットに表示) | もっと低い場所で `setup` するか、高さを下げて作り直す |
| 作り直したアドオンが更新されない / 同じパックが 2 つ並ぶ | パック名とコマンド接頭辞が同じなら同じパック (UUID) として作られ、版はビルドごとに上がる。名前か接頭辞を変えると別のパックになる | ワールドの設定から古い方を外す。同じ名前・接頭辞のまま作り直す |
| 古い版のアドオンで新しい版の変換データを使うと表示が崩れる | 変換データとアドオン (`main.js`) は同じ版で作る前提 (例: Phase 8.3 の 2.5D の立体のデータは、v6.3.0 以前のアドオンでは平らな画面になる) | GUI で作った `.mcaddon` をそのまま使う (変換データとアドオンが常にそろう) |
| スマートフォン・ゲーム機で動くか分からない | 作者が確かめたのは Windows 版だけ ([COMPATIBILITY.md](COMPATIBILITY.md)) | 軽量・標準プリセットから試す。動いた・動かなかったを Issue で知らせてもらえると助かります |

## 変換 (PC)

| 問題 | 原因 | 回避策 |
|---|---|---|
| GPU があるのに CPU で変換される | PyTorch (または torch-directml) が無い、GPU のテスト変換に失敗した、CPU 専用のディザ (Floyd-Steinberg など) を選んだ | 処理ログの `Conversion device:` の行を確かめる。DirectML は Python 3.12 まで |
| GPU で変換しても速くならない | GPU 経路は OkLab での色合わせ・RDO などの処理が多く、変換全体は CPU と同じくらいのことがある | 時間が気になるときは CPU (`--device cpu`) も試す ([PERFORMANCE.md](PERFORMANCE.md) の変換速度) |
| 長い動画の変換に時間がかかる | 動き探索とタイル辞書 (4 と 8 の両方を試す) で 1 フレームずつ符号化している | ログの「残り約 m:ss」を目安に待つ。急ぐときは `--tile-size 8` (3〜4 割速く、データは 0〜1% 増える) |
| 16:9 の動画で上下に黒い帯ができる | 指定した幅・高さの中に縦横比を保って収めている | GUI の「動画の縦横比に合わせる」を押す (例: 128×128 → 128×72) |
| 羊毛・木材のブロックが燃える / ネザーラック・ソウルソイルの火が消えない | 全ブロック・自動パレットは燃えるブロック (羊毛・木材) も使う。ネザーラックとソウルソイルの上の火は消えない (スクリーンは空に面しているので雷でも着火しうる) | 火や溶岩の近くに置かない。燃やしたくないときはパレットを「39 色」以下にする |
| 夜にスクリーンの一部が光る | 「全ブロック」と「39 色」には光るブロック (シーランタン・フロッグライトなど) が入っている (自動パレットには入れていない) | 自動パレットか「拡張 33 色」以下を使う |
| 近くで見るとブロックの模様が目立つ | 石・羊毛・木材は模様のあるテクスチャ (色は平均で合わせている) | 少し離れて見る。模様の無いブロックだけにするならパレットを「基本 16 色」 (コンクリート) にする |
| 「ffmpeg が見つかりません」 | ffmpeg が PATH に無い (EXE 版にも FFmpeg は入っていない) | `winget install Gyan.FFmpeg` で入れるか、`ffmpeg.exe` をツール (EXE) と同じフォルダに置く |

ここに無い問題は [Issue](https://github.com/ntk758/MinecraftAddon_Bedrock_Video-Player/issues/new/choose) で知らせてください。
