## Возможности

- 🧱 **Настоящие блоки**: до 221 вида (бетон, терракота, шерсть, доски, брёвна, камень, руды…). Цвета измерены по текстурам игры, и для каждой сцены автоматически выбирается до 127 цветов.
- 🔊 **Звук остаётся синхронным** даже после паузы и перемотки.
- 🧊 **3D-голограммы**, которые можно обойти: рельеф, выдавленные или скруглённые фигуры и анимации MagicaVoxel (`.vox`).
- 🪄 **Обманка**: фигура, нарисованная для вашего глаза, выглядит объёмной откуда угодно (верно для одного зрителя).
- 🧭 **Пульт** с компасом: воспроизведение, пауза, стоп, перемотка, громкость, следующее/предыдущее видео, список видео.
- 📚 Несколько видео в одном аддоне и, по желанию, плоская версия 3D-видео в том же аддоне.
- 🔓 **Не нужны ни читы, ни экспериментальные функции** (только стабильный Script API).
- 🌐 **10 языков**: сообщения и пульт следуют языку игры каждого игрока.
- 🖼 **Режим изображений (экспериментальный)**: отдельный аддон, показывающий видео текстурами до 30 к/с.

## Быстрый старт

**A. Попробовать пример (без конвертации, около 3 минут)**
1. Скачайте `BlockVideoPlayer-sample-….mcaddon` (плоский) или `BlockVideoPlayer-sample-3d-….mcaddon` (3D) из [последнего релиза](https://github.com/ntk758/MinecraftAddon_Bedrock_Video-Player/releases/latest) и откройте файл, чтобы импортировать его в Minecraft.
2. В настройках мира включите **оба** пакета: пакет поведения и пакет ресурсов (одно название). Читы можно не включать.
3. Найдите ровное открытое место (экран **заменяет блоки там**, используйте тестовый мир). Посмотрите туда, где нужен экран, и введите `/badapple:setup wall`, затем `/badapple:start`.
4. Используйте компас, чтобы открыть пульт. Когда вы впервые входите в мир без экрана, короткое сообщение в чате напомнит эти шаги.

**B. Конвертировать своё видео в браузере (без установки, бета)**
- Откройте [веб-конвертер](https://ntk758.github.io/MinecraftAddon_Bedrock_Video-Player/), выберите видео и нажмите *Создать .mcaddon*. Работает на Windows, Mac, Chromebook и телефонах; ваши видео не покидают браузер.
- Подходят и картинки, видео с камеры, `.vox` и модели MMD с танцем (`.pmx` + `.vmd`). После сборки можно посмотреть, как это будет выглядеть в Minecraft.
- Для **Minecraft 1.21.80–1.26.0** выберите это в *Версии Minecraft* (таким аддонам нужны читы, и они используют команды `/scriptevent`).

**C. Конвертировать в Windows (быстрее, аддоны меньше)**
1. Распакуйте `BlockVideoPlayer-…-windows-x64.zip` из [последнего релиза](https://github.com/ntk758/MinecraftAddon_Bedrock_Video-Player/releases/latest) и запустите `BlockVideoPlayer.exe` (Python не нужен). **FFmpeg нужен отдельно**: выполните `winget install Gyan.FFmpeg` или положите `ffmpeg.exe` рядом с EXE.
2. При первом запуске открывается помощник: он проверяет компьютер, предлагает настройки и показывает команды для воспроизведения. Без него: *Добавить видео* → *Подогнать под пропорции видео* → *Создать .mcaddon*.
3. Если **оценка нагрузки** показывает *тяжело*, уменьшите ширину, высоту или к/с.

## Команды

`badapple` — префикс команд (вы выбираете его при конвертации). Команды могут использовать операторы; с включёнными читами работает и старая форма `/scriptevent badapple:…`.

| Команда | Что делает |
|---|---|
| `/badapple:setup` | Положить экран здесь на пол (3D: стоит в 2 блоках к северу) |
| `/badapple:setup wall` | Поставить плоский экран, как телевизор, в 3 блоках перед вами |
| `/badapple:setup face` | Положить на пол, но повернуть по направлению взгляда |
| `/badapple:start` | Воспроизвести выбранное видео с начала |
| `/badapple:play <ID>` / `/badapple:list` | Воспроизвести видео / список видео |
| `/badapple:remote` | Открыть пульт (как компас) |
| `/badapple:stop` | Остановить и очистить экран |
| `/badapple:stats` | Реальные к/с, TPS и опоздавшие кадры последнего воспроизведения |

## Режим изображений (экспериментальный)

Отметьте *Создать и аддон в режиме изображений* в приложении для Windows или в веб-конвертере (или выполните `python convert_image_mode.py video.mp4`). Получится второй файл `<название>_image.mcaddon`. В игре: `/badapple_img:setup`, затем `/badapple_img:start`. Он воспроизводит до 30 к/с, не заменяя блоки, но использует память текстур, поэтому берите короткие видео. **В настоящем Minecraft ещё не проверялся.** Подробнее: [docs/IMAGE_MODE.md](docs/IMAGE_MODE.md) (на японском).

## Требования

| | |
|---|---|
| Minecraft | Bedrock Edition **1.26.10 или новее** (1.21.80–1.26.0: создайте в веб-конвертере) |
| Конвертер | EXE для Windows 10/11 или любой современный браузер. Из исходников: Python 3.12 + FFmpeg (командная строка работает и в Linux) |
| GPU (необязательно) | NVIDIA (CUDA), AMD (ROCm / DirectML) или Intel (DirectML); подойдёт и процессор |

Проверено на одном ПК с Windows 11. Телефоны, консоли и серверы должны работать, но **ещё не проверены** ([совместимость](docs/COMPATIBILITY.md)).

## Частые вопросы

- **Java Edition?** Нет, только Bedrock.
- **Нет звука?** Включите оба пакета, проверьте громкость в пульте и в игре и перезапустите Minecraft после импорта.
- **Тормозит?** Уменьшите размер или к/с и посмотрите `/badapple:stats`. Подробнее в [известных проблемах](docs/KNOWN_ISSUES.md).
- **Свои видео**: распространение аддона из чужого видео (аниме, клипы, трансляции) может нарушать авторские права. Делитесь только видео, которые сделали сами или которыми разрешено делиться.
